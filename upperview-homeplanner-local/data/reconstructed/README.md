# Reconstructed Data

Status: reconstructed unless a file says otherwise.

This folder contains local responses inferred from the frontend JavaScript contracts. These files are not historical UpperView backend records.

The sample catalog uses neutral placeholder identities:

- Neighborhood ID: `1`
- Plan ID: `101`
- Elevation ID: `1001`
- Floorplan option IDs: `2000-2002`

The name `Reconstructed Sample Plan` is intentionally neutral because no real UpperView plan names were recovered from the HomePlanner backend.
